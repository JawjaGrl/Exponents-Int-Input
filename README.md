# Exponents-Int-Input
This is day two Beginner Intro Python-Math Expressions
"This program was built using Claude Code to demonstrate input, integer conversion, and exponent operations for a day two beginner Python lesson. The first version used the string constructor to combine text and numbers in the print statements, a concept not yet covered in the curriculum at this stage. After flagging this mismatch, the program was rewritten using commas in the print statements instead, keeping it aligned with what students have actually learned by day two."
